# 澜庭档案：夜班失踪事件

中式恐怖网页 ARG 解谜游戏。在废弃的养老院档案系统里搜索关键词，揭开弟弟失踪的真相。

## 游玩

1. 用浏览器打开 `index.html`，或本地启动：
   ```bash
   npx serve lanting-archive
   ```
2. 进入档案系统，在搜索框输入关键词推进剧情。
3. 首次建议搜索：**沈屿**
4. 卡关时可登录（见 `archive/login.html`）解锁护理部/外包线档案。

## 结局

在「我该怎么办」页输入：

- `公开` — 结局一
- `烧掉` — 结局二
- `守望者夜班` — 坏结局
